# virus_hack_LOL

A fun prank Python script that displays a "hacked" message and plays a fullscreen video with sound. **This is purely for educational and entertainment purposes!**

## 🎯 What it does

This project is a harmless prank application that:
- Shows a popup message saying "You've been hacked (just kidding, it's for learning! )"
- Plays a video (`video.mp4`) in fullscreen mode with audio
- Loops the video continuously
- Can be stopped by pressing the 'Q' key

## 📋 Requirements

- Python 3.x
- VLC media player installed on your system

## 🚀 Installation

1. Clone this repository: 
```bash
git clone https://github.com/anassalien123/virus_hack_LOL.git
cd virus_hack_LOL
```

2. Install the required dependencies:
```bash
pip install -r requirements.txt
```

3. Make sure you have VLC media player installed on your system

## 💻 Usage

Run the script: 
```bash
python virus.py
```

To stop the video, press the `Q` key.

## 📦 Dependencies

- `tkinter` - For popup message display
- `python-vlc` - For video playback
- `keyboard` - For detecting key presses
- `pygame`, `opencv-python`, `psutil`, `numpy` - Additional utilities
